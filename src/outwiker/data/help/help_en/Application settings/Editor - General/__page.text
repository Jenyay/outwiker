!!! Editor - General

%center%Attach:outwiker_opt_editor_general.png

This section contains settings for the text editor used for taking notes.

The %notice%Font%% group allows you to customize the font face and size.

Use the %notice%Show line numbers%% checkbox to enable or disable the display of line numbering to the left of the text.

The width of the line numbering area can be adjusted using the %notice%Line number margin width%% parameter. This value is set in pixels. If set to 0, the width will be determined automatically to be the minimum necessary.

If the %notice%Use spaces instead of tabs%% checkbox is enabled, pressing the %code%Tab%% key will insert a specific number of space characters instead of a tab character. The number of spaces is defined in the %notice%Tab size%% field (the default value is 4).

The text editor can handle %code%Home%% / %code%End%% keys in two ways. Pressing these keys will move the cursor either to the beginning / end of the current line, or to the beginning / end of the current paragraph (considering word wrap). This behavior is toggled via the %notice%Home / End keys move cursor to the start / end of%% drop-down list. The available options are either %notice%Line%% or %notice%Paragraph%%.

In addition to the parameters listed here, you can configure the text editor's UI colors in the page://settings_interface_colors section. The page://settings_editor_html_editor and page://settings_editor_wiki_editor sections also allow you to customize syntax highlighting for HTML and wiki pages, respectively.
