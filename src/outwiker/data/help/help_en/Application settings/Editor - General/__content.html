Editor - General




This section contains settings for the text editor used for taking notes.

The Font group allows you to customize the font face and size.

Use the Show line numbers checkbox to enable or disable the display of line numbering to the left of the text.

The width of the line numbering area can be adjusted using the Line number margin width parameter. This value is set in pixels. If set to 0, the width will be determined automatically to be the minimum necessary.

If the Use spaces instead of tabs checkbox is enabled, pressing the Tab key will insert a specific number of space characters instead of a tab character. The number of spaces is defined in the Tab size field (the default value is 4).

The text editor can handle Home / End keys in two ways. Pressing these keys will move the cursor either to the beginning / end of the current line, or to the beginning / end of the current paragraph (considering word wrap). This behavior is toggled via the Home / End keys move cursor to the start / end of drop-down list. The available options are either Line or Paragraph.

In addition to the parameters listed here, you can configure the text editor's UI colors in the Interface - Colors section. The Editor - HTML editor and Editor - Wiki editor sections also allow you to customize syntax highlighting for HTML and wiki pages, respectively.
