Interface - General




Confirm before exit. If this check box is selected, a confirmation dialog will appear when exiting OutWiker.

The Autosave interval in seconds field allows you to specify how frequently the currently open note is saved. If set to 0, the timer-based autosave is disabled. However, notes are still saved during other events, such as exiting the program, switching between notes, or toggling between the "Wiki," "View," and "HTML" tabs. Additionally, you can manually save a note using the File - Save menu item.

The Recent icons history size field sets the number of icons stored in the "recently used" list within the page creation and property dialogs.

The Recent note tree history size field determines the number of recently opened note trees displayed in the File menu.

If the Open last note tree on startup check box is selected, the last used note tree will automatically open when the program starts.

The Notification timeout in seconds field sets the display duration for the information windows that appear in the bottom-right corner to notify you of errors or program events.

Certain page types (such as wiki pages and HTML pages) can be displayed in different modes: Preview mode or Edit mode. Using the Default page opening mode drop-down list, you can choose which mode is active when a page is selected in the note tree. You can set pages to always open in Preview or Edit mode, or choose to remember the last used mode for each specific page.

The Language drop-down list allows you to select one of the supported interface languages. If Auto is selected, the language is determined by your operating system settings. If you would like to help translate the application into another language, you can do so via the crowdin.com localization service.
