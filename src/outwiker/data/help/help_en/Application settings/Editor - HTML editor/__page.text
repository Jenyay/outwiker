!! Editor - HTML Editor

%center%Attach:outwiker_opt_editor_html.png

This section contains settings for HTML syntax highlighting in the note editor on [[HTML pages -> page://html-page]] or within the HTML source code view tab on [[wiki pages -> page://wiki-page]]. Here, you can define the font color and style for HTML tags, attributes, numbers, HTML comments, as well as unknown HTML tags that are not found in the dictionary of known HTML tags.

An example of HTML syntax highlighting is shown in the following image:

%center%%thumb width=600%Attach:html_highlight.png%%

The font name and size for the note editor can be configured in the page://settings_editor_general section.
