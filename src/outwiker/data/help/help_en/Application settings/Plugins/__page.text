!! Plugins

%center%Attach:outwiker_opt_plugins.png

This section allows you to view the list of installed [[plugins -> page://plugins]]. Selecting a plugin from the list displays information about it, including its name, version number, a brief description, and a link to the plugin's website, if available.

A check box before the plugin name indicates that the plugin is activated. Therefore, you do not need to remove a plugin from the %info%plugins%% subdirectory within the [[configuration directories -> page://config-dirs]] to disable it. You can deactivate it in this settings section.

A link to the [[website page -> https://jenyay.net/Outwiker/PluginsEn]] with a list of supported plugins is located at the bottom of the window.

Plugins may add their own settings sections as subsection within this section.
