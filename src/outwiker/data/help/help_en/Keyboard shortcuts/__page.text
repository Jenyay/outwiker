!! Keyboard shortcuts

To speed up your workflow, you can assign hotkeys to almost any action available in the application menus. This can be configured in the [[application settings -> page://settings]] under the %notice%[[Interface - Keyboard shortcuts -> page://settings_interface_hotkeys]]%% section.

The following table lists the default keyboard shortcuts used in the application.
