Директории настроек


Под директориями настроек понимаются следующие директории:
  • Директория, где расположен файл настроек outwiker.ini и файл лога работы outwiker.log.
  • Директория с плагинами - plugins.
  • Директория со значками для заметок - iconset.
  • Директория со словарями для проверки орфографии - spell.
  • Директория со стилями страниц - styles.
  • Директория со стилями оформления текста для викистраниц - textstyles.
Имеется несколько путей, где OutWiker пытается найти директории настроек.

Портабельный режим (версия под Windows)


Если файл настроек outwiker.ini расположен в той же директории, что и запускаемый файл (outwiker.exe), в этом случае OutWiker работает в портабельном режиме. Это значит, что программа для своих нужд использует только директории внутри своей основной директории. В таком режиме директории настроек расположены в следующих поддиректориях внутри директории приложения:
  • Файл настроек outwiker.ini и файл лога работы outwiker.log располагаются непосредственно в директории приложения.
  • Директория с плагинами - директория plugins в директории с программой.
  • Директория со значками для заметок - lib\outwiker\data\iconset.
  • Директория со словарями для проверки орфографии - lib\outwiker\data\spell.
  • Директория со стилями страниц - lib\outwiker\data\styles.
  • Директория со стилями оформления текста для викистраниц - lib\outwiker\data\textstyles.

Обычный режим (версия под Windows)


В обычном режиме директории настроек ищутся в тех же местах, что были перечислены в разделе про портабельный режим, но что-то менять в этих директориях не рекомендуется, а предлагается работать с директориями внутри внутри профиля пользователя:
  • Файл настроек outwiker.ini и файл лога работы outwiker.log располагаются в директории C:\Users\USERNAME\AppData\Roaming\outwiker\.
  • Директория с плагинами - C:\Users\USERNAME\AppData\Roaming\outwiker\plugins.
  • Директория со значками для заметок - C:\Users\USERNAME\AppData\Roaming\outwiker\iconset.
  • Директория со словарями для проверки орфографии - C:\Users\USERNAME\AppData\Roaming\outwiker\spell.
  • Директория со стилями страниц - C:\Users\USERNAME\AppData\Roaming\outwiker\styles.
  • Директория со стилями оформления текста для викистраниц - C:\Users\USERNAME\AppData\Roaming\outwiker\textstyles.
Здесь предполагается, что директория пользователя расположена на диске C: по адресу C:\Users\USERNAME\, где USERNAME - это имя пользователя в системе.

Директории настроек под Linux


Путь до директорий настроек под Linux зависит от того, каким образом запускается приложение OutWiker: из исходных кодов, как flatpak-пакет или snap-пакет.

При запуске приложения OutWiker из исходников корневая директория настроек определяется по следующему правилу.
  • Если установлена переменная окружения XDG_CONFIG_HOME, то путь до корневой директории настроек будет следующий: "$XDG_CONFIG_HOME/outwiker".
  • Если переменная окружения XDG_CONFIG_HOME не установлена, то корневой директорией для настроек будет считаться ~/.config/outwiker.
При запуске OutWiker из flatpak-пакета корневой директорией настроек будет ~/.var/app/net.jenyay.Outwiker/config/outwiker/

При запуске OutWiker из snap-пакета корневой директорией настроек будет ~/snap/outwiker/current/.config/outwiker/

Внутри корневой директории настроек располагаются:
  • Файл настроек outwiker.ini и файл лога работы outwiker.log.
  • Директория с плагинами - plugins.
  • Директория со значками для заметок - iconset.
  • Директория со словарями для проверки орфографии - spell.
  • Директория со стилями страниц - styles.
  • Директория со стилями оформления текста для викистраниц - textstyles.

Переменная окружения OUTWIKER_PATH


OutWiker позволяет добавить еще одну директорию, которая будет использоваться как корневая директория для настроек. Путь к этой директории может быть записан в переменную окружения OUTWIKER_PATH. Внутри этой директории могут располагаться все те же поддиректории, которые упоминались ранее: plugins, iconset, spell, styles, textstyles.
