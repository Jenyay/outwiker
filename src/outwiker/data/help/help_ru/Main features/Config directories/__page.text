!! Директории настроек

Под %notice%директориями настроек%% понимаются следующие директории:

* Директория, где расположен файл настроек %notice%outwiker.ini%% и файл лога работы %notice%outwiker.log%%.
* Директория с плагинами  - %notice%plugins%%.
* Директория со значками для заметок - %notice%iconset%%.
* Директория со словарями для проверки орфографии - %notice%spell%%.
* Директория со стилями страниц - %notice%styles%%.
* Директория со стилями оформления текста для викистраниц - %notice%textstyles%%.

Имеется несколько путей, где OutWiker пытается найти директории настроек. 

!!! [[#portable]] Портабельный режим (версия под Windows)

Если файл настроек %notice%outwiker.ini%% расположен в той же директории, что и запускаемый файл (%notice%outwiker.exe%%), в этом случае OutWiker работает %notice%портабельном режиме%%. Это значит, что программа для своих нужд использует только директории внутри своей основной директории. В таком режиме директории настроек расположены в следующих поддиректориях внутри директории приложения:

* Файл настроек %notice%outwiker.ini%% и файл лога работы %notice%outwiker.log%% располагаются непосредственно в директории приложения.
* Директория с плагинами  - директория %notice%plugins%% в директории с программой.
* Директория со значками для заметок - %notice%lib\outwiker\data\iconset%%.
* Директория со словарями для проверки орфографии - %notice%lib\outwiker\data\spell%%.
* Директория со стилями страниц - %notice%lib\outwiker\data\styles%%.
* Директория со стилями оформления текста для викистраниц - %notice%lib\outwiker\data\textstyles%%.

!!! [[#normal_win]] Обычный режим (версия под Windows)

В обычном режиме директории настроек ищутся в тех же местах, что были перечислены в разделе про [[портабельный режим -> #portable]], но что-то менять в этих директориях не рекомендуется, а предлагается работать с директориями внутри внутри профиля пользователя:

* Файл настроек %notice%outwiker.ini%% и файл лога работы %notice%outwiker.log%% располагаются в директории %notice%C:\Users\USERNAME\AppData\Roaming\outwiker\%%.
* Директория с плагинами  - %notice%C:\Users\USERNAME\AppData\Roaming\outwiker\plugins%%.
* Директория со значками для заметок - %notice%C:\Users\USERNAME\AppData\Roaming\outwiker\iconset%%.
* Директория со словарями для проверки орфографии - %notice%C:\Users\USERNAME\AppData\Roaming\outwiker\spell%%.
* Директория со стилями страниц - %notice%C:\Users\USERNAME\AppData\Roaming\outwiker\styles%%.
* Директория со стилями оформления текста для викистраниц - %notice%C:\Users\USERNAME\AppData\Roaming\outwiker\textstyles%%.

Здесь предполагается, что директория пользователя расположена на диске C:\ по адресу %notice%C:\Users\'''USERNAME'''\%%, где '''USERNAME''' - это имя пользователя в системе.


!!! [[#linux]] Директории настроек под Linux

Путь до директорий настроек под Linux зависит от того, каким образом запускается приложение OutWiker: из исходных кодов, как flatpak-пакет или snap-пакет.

При запуске приложения OutWiker '''из исходников''' корневая директория настроек определяется по следующему правилу.
* Если установлена переменная окружения %notice%XDG_CONFIG_HOME%%, то путь до корневой директории настроек будет следующий: %notice%"$XDG_CONFIG_HOME/outwiker"%%. 
* Если переменная окружения %notice%XDG_CONFIG_HOME%% не установлена, то корневой директорией до настроек будет считаться %notice%~/.config/outwiker%%.

При запуске OutWiker из '''flatpak-пакета''' корневой директорией настроек будет %notice%~/.var/app/net.jenyay.Outwiker/config/outwiker/%%

При запуске OutWiker из '''snap-пакета''' корневой директорией настроек будет %notice%~/snap/outwiker/current/.config/outwiker/%%

Внутри корневой директории настроек располагаются:

* Файл настроек %notice%outwiker.ini%% и файл лога работы %notice%outwiker.log%%.
* Директория с плагинами  - %notice%plugins%%.
* Директория со значками для заметок - %notice%iconset%%.
* Директория со словарями для проверки орфографии - %notice%spell%%.
* Директория со стилями страниц - %notice%styles%%.
* Директория со стилями оформления текста для викистраниц - %notice%textstyles%%.
