!! Директории настроек

Под директориями настроек понимаются следующие директории:

* Директория, где расположен файл настроек %info%outwiker.ini%% и файл лога работы %info%outwiker.log%%.
* Директория с плагинами  - %info%plugins%%.
* Директория со значками для заметок - %info%iconset%%.
* Директория со словарями для проверки орфографии - %info%spell%%.
* Директория со стилями страниц - %info%styles%%.
* Директория со стилями оформления текста для викистраниц - %info%textstyles%%.

Имеется несколько путей, где OutWiker пытается найти директории настроек. 

!!! [[#portable]] Портабельный режим (версия под Windows)

Если файл настроек %info%outwiker.ini%% расположен в той же директории, что и запускаемый файл (%info%outwiker.exe%%), в этом случае OutWiker работает в портабельном режиме. Это значит, что программа для своих нужд использует только директории внутри своей основной директории. В таком режиме директории настроек расположены в следующих поддиректориях внутри директории приложения:

* Файл настроек %info%outwiker.ini%% и файл лога работы %info%outwiker.log%% располагаются непосредственно в директории приложения.
* Директория с плагинами  - директория %info%plugins%% в директории с программой.
* Директория со значками для заметок - %info%lib\outwiker\data\iconset%%.
* Директория со словарями для проверки орфографии - %info%lib\outwiker\data\spell%%.
* Директория со стилями страниц - %info%lib\outwiker\data\styles%%.
* Директория со стилями оформления текста для викистраниц - %info%lib\outwiker\data\textstyles%%.

!!! [[#normal_win]] Обычный режим (версия под Windows)

В обычном режиме директории настроек ищутся в тех же местах, что были перечислены в разделе про [[портабельный режим -> #portable]], но что-то менять в этих директориях не рекомендуется, а предлагается работать с директориями внутри внутри профиля пользователя:

* Файл настроек %info%outwiker.ini%% и файл лога работы %info%outwiker.log%% располагаются в директории %info%C:\Users\USERNAME\AppData\Roaming\outwiker\%%.
* Директория с плагинами  - %info%C:\Users\USERNAME\AppData\Roaming\outwiker\plugins%%.
* Директория со значками для заметок - %info%C:\Users\USERNAME\AppData\Roaming\outwiker\iconset%%.
* Директория со словарями для проверки орфографии - %info%C:\Users\USERNAME\AppData\Roaming\outwiker\spell%%.
* Директория со стилями страниц - %info%C:\Users\USERNAME\AppData\Roaming\outwiker\styles%%.
* Директория со стилями оформления текста для викистраниц - %info%C:\Users\USERNAME\AppData\Roaming\outwiker\textstyles%%.

Здесь предполагается, что директория пользователя расположена на диске C: по адресу %info%C:\Users\'''USERNAME'''\%%, где '''USERNAME''' - это имя пользователя в системе.


!!! [[#linux]] Директории настроек под Linux

Путь до директорий настроек под Linux зависит от того, каким образом запускается приложение OutWiker: из исходных кодов, как flatpak-пакет или snap-пакет.

При запуске приложения OutWiker '''из исходников''' корневая директория настроек определяется по следующему правилу.
* Если установлена переменная окружения %code%XDG_CONFIG_HOME%%, то путь до корневой директории настроек будет следующий: %info%"$XDG_CONFIG_HOME/outwiker"%%. 
* Если переменная окружения %code%XDG_CONFIG_HOME%% не установлена, то корневой директорией для настроек будет считаться %info%~/.config/outwiker%%.

При запуске OutWiker из '''flatpak-пакета''' корневой директорией настроек будет %info%~/.var/app/net.jenyay.Outwiker/config/outwiker/%%

При запуске OutWiker из '''snap-пакета''' корневой директорией настроек будет %info%~/snap/outwiker/current/.config/outwiker/%%

Внутри корневой директории настроек располагаются:

* Файл настроек %info%outwiker.ini%% и файл лога работы %info%outwiker.log%%.
* Директория с плагинами  - %info%plugins%%.
* Директория со значками для заметок - %info%iconset%%.
* Директория со словарями для проверки орфографии - %info%spell%%.
* Директория со стилями страниц - %info%styles%%.
* Директория со стилями оформления текста для викистраниц - %info%textstyles%%.

!!! Переменная окружения OUTWIKER_PATH

OutWiker позволяет добавить еще одну директорию, которая будет использоваться как корневая директория для настроек. Путь к этой директории может быть записан в переменную окружения %code%OUTWIKER_PATH%%. Внутри этой директории могут располагаться все те же поддиректории, которые упоминались ранее: %info%plugins%%, %info%iconset%%, %info%spell%%, %info%styles%%, %info%textstyles%%.
