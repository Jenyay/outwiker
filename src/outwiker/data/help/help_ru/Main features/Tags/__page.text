!!! [[#addtags]] Добавление тегов к заметкам

К каждой заметке можно добавлять любое количество тегов, которые затем могут быть использованы для поиска нужной заметки. 

Теги можно добавлять к заметкам несколькими способами. Во-первых, их можно добавлять при создании заметки. При этом теги должны быть перечислены через запятую. 

%center% Attach:pageproperties.png

Теги можно редактировать и после создания заметки с помощью диалога "Редактирование свойств страницы", который вызывается с помощью пункта меню %notice%"Дерево - Свойства страницы..."%%, а также при двойном клике по заметке в дереве заметок или по вкладке с открытой заметкой.

Во-вторых, теги можно добавлять и из главного окна не вызывая свойства страницы. Для этого предназначено окно "Теги". Если окно "Теги" скрыто, то его можно открыть с помощью пункта меню %notice%"Вид - Теги"%%.

%center% Attach:tags_panel.png

Фон тегов, установленных для выбранной страницы, выделяется цветом (по умолчанию желтым).

На панели "Теги" размер шрифта для каждого тега зависит от частоты использования данного тега среди всех заметок (чем популярнее тег, тем более крупным шрифтом он отображается).

При щелчке по тегу левой кнопкой мыши появляется список страниц, которые также помечены этим тегом. 

%center% %thumb width=700%Attach:popup.png%%


!!! [[#group]] Групповые операции с тегами

!!!! [[#add-remove]] Групповое добавление и удаление тегов

OutWiker позволяет добавлять или удалять теги в целой ветке заметок. Для того, чтобы добавить теги к ветке заметок, проделайте следующие операции:

1. Выберите заметку, которая является корневой для ветки, к которой нужно добавить один или несколько тегов. Если нужно добавить тег ко всему дереву, выберите корень дерева.
2. Выберите пункт меню %notice%"Инструменты - Теги - Добавить теги к ветке..."%%. Появится следующий диалог:

%center% Attach:addtag.png

%center% Attach:addtag_popup.png

3. Выберите теги, которые нужно добавить к заметкам (теги разделяются запятыми). Можно выбрать существующие теги или ввести новые.
4. Нажмите кнопку "OK", после чего выбранные теги будут добавлены к ветке заметок. Выбранные теги также добавляются и к выбранной в данный момент заметке.

Для того, чтобы удалить теги из ветки или всего дерева, нужно проделать те же операции, описаны выше для добавления тегов с той лишь разницей, что на шаге 2 нужно выбрать пункт меню %notice%"Инструменты - Теги - Удалить теги из ветки..."%%.


!!!! [[#rename]] Переименование тегов

Для того, чтобы переименовать существующий тег, выберите пункт меню %notice%"Инструменты - Теги - Переименовать тег..."%%. Появится следующий диалог:

%center%Attach:renametag.png

В облаке тегов выберите тег, который нужно переименовать (выбранный тег выделяется цветом), а в нижнем поле ввода введите новое имя тега. Нажмите кнопку "OK", после чего во всем дереве заметок вместо выбранного тега будет добавлен тег с новым именем.
