!! Вложения

Работа с прикрепленными файлами и папками (вложениями) - это одна из основных особенностей программы OutWiker. Вложения могут содержать как файлы, так и папки с файлами. Файлы вложенных картинок можно вставлять в текст страницы. Например:

%center%Attach:cat.jpg

Также можно вставлять ссылки на вложенные файлы: [[Attach:cat.jpg]], в этом случае при клике на такую ссылку будет запущена внешняя программа для открытия файла соответствующего типа.

Все прикрепленные к заметке файлы хранятся во вложенной папке %info%__attach%% внутри папки с заметкой. 

Чтобы прикрепить новые файлы, их можно перетащить мышкой в окно "Вложения", воспользоваться кнопкой %notice%"Прикрепить файлы"%% на панели инструментов или выбрать пункт меню %notice%"Инструменты - Вложения - Прикрепить файлы..."%%.

%center%Attach:attach_panel.png

Кнопки на панели инструментов окна "Вложения" позволяют выполнить следующие действия:

* Добавить (скопировать) новые файлы к вложениям (кнопка %notice%"Прикрепить файлы..."%%).
* Добавить во вложения (скопировать) существующую папку (кнопка %notice%"Прикрепить папку..."%%)
* Создать пустую папку (кнопка %notice%"Создать новую прикрепленную папку"%%).
* Удалить прикрепленные файлы или папки (кнопка %notice%"Удалить вложения"%%).
* Изменить имя прикрепленного файла или папки (кнопка %notice%"Переименовать вложение"%%).
* Выбрать все прикрепленные файлы и папки (кнопка %notice%"Выбрать всё"%%).
* Вставить на страницу заметки ссылку на выбранные на панели "Вложения" прикрепленные файлы или папки (кнопка %notice%"Вставить ссылку на вложения"%%).
* Открыть во внешней программе или запустить на выполнение выбранные прикрепленные файлы (кнопка %notice%"Запустить вложения"%%).
* Открыть папку с прикрепленными файлами в системном файловом менеджере (кнопка %notice%"Открыть папку с вложениями"%%).
* Скопировать путь до папки с прикрепленными файлами в буфер обмена (кнопка %notice%"Копировать путь до вложений"%%).
