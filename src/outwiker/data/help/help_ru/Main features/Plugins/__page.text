!! Плагины

Плагины (дополнения) позволяют дополнительно расширять возможности OutWiker по сравнению с базовыми возможностями. Дополнительные плагины вы можете найти [[на этой странице -> https://jenyay.net/Outwiker/Plugins]] сайта программы. Большое количество плагинов включены в инсталятор OutWiker и могут быть установлены вместе с приложением. 

Вы можете создавать свои плагины, которые пишутся на языке Python и представляют собой директорию со скриптами и файлом манифеста %notice%plugin.xml%%. 

Для установки дополнительного плагина необходимо скопировать директорию с исходным кодом плагина и файлом манифеста в поддиректорию %notice%plugins%% в [[директории настроек -> page://config-dirs]]. Директорию с плагинами можно открыть в файловом менеджере вашей операционной системы непосредственно из OutWiker, выбрав пункт меню %notice%"Справка - Открыть папку с плагинами"%%.

После перезапуска OutWiker установленный плагин появится в [[диалоге параметров  -> page://settings]] в разделе [[Плагины -> page://settings-plugins]]:

%center%Attach:outwiker_opt_plugins.png

Если вы написали новый плагин и хотите, чтобы он был помещен на страницу с плагинами, пришлите его на почту [[mailto:jenyay.ilin@gmail.com | jenyay.ilin@gmail.com]] с подробным описанием, что он делает. Прилагающиеся Unit-тесты приветствуются.
