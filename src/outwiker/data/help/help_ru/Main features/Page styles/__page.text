!! Стили страниц

Для [[вики-страниц -> page://wiki-page]] и [[HTML-страниц -> page://html-page]] можно устанавливать стили оформления. Для выбора стиля страницы предназначена вкладка "Внешний вид" диалога свойств страницы.

%center% Attach:styles_list.png 

Стили для страниц хранятся в поддиректории %notice%styles%% внутри [[директорий настроек -> page://config-dirs]].

При установке стиля в директорию страницы копируются файл %notice%__style.html%% и поддиректория %notice%__style%%, если она есть в выбранном стиле. Таким образом, решается проблема, если на одном компьютере установлен какой-то стиль, а на другом - нет. В то же время такой подход позволяет индивидуально подстраивать стили для каждой страницы. При установки стиля по умолчанию файл %notice%__style.html%% и поддиректория %notice%__style%% удаляются.
