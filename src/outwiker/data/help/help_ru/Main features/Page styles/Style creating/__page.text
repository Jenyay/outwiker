!! Создание стилей страниц

[[Стиль оформления -> page://styles]] страниц заметок представляет собой директорию, в которой обязательно должен быть файл %notice%__style.html%% и не обязательная поддиректория %notice%__style%%.

Содержимое %notice%__style.html%% - это обычный HTML-файл в кодировке UTF-8, который содержит некоторые макросы подстановки. В процессе генерации окончательного вида страницы эти макросы подстановки заменяются на содержимое страницы или дополнительные параметры, которые описаны [[ниже -> #macros]]. Для примера, так выглядит стиль по умолчанию:

[@
<html>
<head>
    <meta http-equiv='content-type' content='text/html; charset=utf-8'/>

    <style type="text/css">
        body, div, p, table {
            font-size:${fontsize}pt;
            font-family:$fontfamily;
        }

        img{border:none}
        $userstyle
    </style>
    $userhead
</head>

<body>
<P>$content</P>
</body>
</html>
@]

!!! [[#macros]] Макросы подстановки

В файле %notice%__style.html%% содержатся специальные макросы подстановки, которые начинаются с символа "$", за которым идет имя макроса, возможно окруженное фигурными скобками, например: %notice%$content%% или %notice%${content}%%. Второй случай нужен, если сразу за макросом должен располагаться какой-то текст впритык к нему без пробелов. На данный момент стили страниц поддерживают следующие макросы подстановки:

* %notice%$content%% - заменяется содержимым страницы.
* %notice%$fontsize%% - размер шрифта, установленного в настройках. Измеряется в пунктах (pt).
* %notice%$fontfamily%% - имя шрифта, установленного в настройках.
* %notice%$userstyle%% - дополнительные стили, которые могут создаваться в процессе разбора викистраниц.
* %notice%$userhead%% - дополнительные теги внутри тега &lt;head&gt;...&lt;/head&gt;, которые могут создаваться в процессе разбора викистраниц.

Директория %notice%__style%% является не обязательной. В ней могут располагаться картинки и файлы со стилями CSS. Однако хранить стили CSS в этой директории не желательно, лучше их помещать непосредственно в файл %notice%__style.html%%. В первую очередь это связано с кэшированием стилей при запуске программы под Linux. Если несколько стилей имеют файлы CSS с одинаковыми именами, то при переключении между этими стилями одноименные файлы CSS при рендеринге HTML могут обновляться не сразу.
