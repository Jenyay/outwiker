Сочетания клавиш


Для ускорения работы с приложением на каждое действие, которое упоминается в пунктах меню, можно установить горячие клавиши. Это делается через диалог настроек программы в разделе Интерфейс - Сочетания клавиш.

В следующей таблице приведены сочетания клавиш, которые используются в приложении по умолчанию.
