!! Ссылки на страницы

В каждой заметке можно вставлять ссылки на другую страницу. Ссылаться на страницы можно двумя способами:
* По идентификатору страницы.
* По имени заметки или ее относительному пути (такой способ использовать не рекомендуется).

Для создания ссылок любого типа можно использовать тег &lt;a href="..."&gt; на [[HTML-страницах -> page://html-page]] или специальные команды для [[ссылок -> page://wiki-links]] на [[викистраницах -> page://wiki-page]].


!!! Ссылки по уникальному идентификатору

В OutWiker есть возможность ссылаться на страницы по их уникальным идентификаторам, которые не зависят от имени и расположения страницы, поэтому при переименовании и перемещении страниц ссылки продолжают оставаться рабочими. 

Для того, чтобы скопировать ссылку на страницу по идентификатору, нужно выбрать пункт меню "Инструменты -> Копировать ссылку на страницу" или выбрать одноименный пункт в контекстном меню, появляющийся при щелчке правой кнопкой мыши на заметку в дереве. Например, для этой страницы такая ссылка выглядит следующим образом: [[page://__a31ba2cf-93a2-4ed1-b3a3-116104c171e2 -> page://__a31ba2cf-93a2-4ed1-b3a3-116104c171e2]]. 

Ссылка начинается с "page://", за которой следует идентификатор страницы.

Примеры ссылок:

* [[page://__93dc4b03-424f-4d7f-a344-f293c93230d9 | Викикоманды]]
* [[Викикоманды -> page://__10b622cd-7ea7-4267-97e9-697fcf869486]]
* page://__93dc4b03-424f-4d7f-a344-f293c93230d9
* [[page://__93dc4b03-424f-4d7f-a344-f293c93230d9]]

При использовании ссылок по уникальному идентификатору можно ссылаться не только на другую страницу, но и на якорь на другой странице. В этом случае ссылка будет выглядеть следующим образом: [[page://__10b622cd-7ea7-4267-97e9-697fcf869486/#anchor  -> page://__10b622cd-7ea7-4267-97e9-697fcf869486/#anchor]]



!!! Ссылки по имени

Ссылки по имени напоминают ссылки на пути в UNIX-системах, и выглядят они следующим образом: {+Имя страницы 1/ Имя страницы 2/.../Имя конечной страницы+}. 

Если ссылка начинается с символа "/", то поиск страницы начинается с корня дерева заметок. Если же символа "/" в начале ссылки нет, то сначала осуществляется поиск, начиная с текущей страницы, а если искомая страница не найдена, то с корня.

Примеры ссылок, оформленных с помощью тега &lt;a ...&gt;...&lt;/a&gt; (так не рекомендуется поступать на викистраницах):

* [=<a href="/Типы страниц/Викистраница/Викикоманды">/Типы страниц/Викистраница/Викикоманды</a>=] (со слешем в начале ссылки работает только в Windows)
* [=<a href="Типы страниц/Викистраница/Викикоманды">Типы страниц/Викистраница/Викикоманды</a>=]
* [=<a href="Дочерняя страница">Дочерняя страница</a>=]

Примеры ссылок, оформленных с помощью викинотации:

* [[/Типы страниц/Викистраница/Викикоманды]] (со слешем в начале ссылки работает только в Windows)
* [[Типы страниц/Викистраница/Викикоманды]]
* [[Дочерняя страница]]

Ссылки по имени можно считать устаревшим, поскольку при переименовании или перемещении страницы, на которую установлена ссылка, такие ссылки перестают работать, их нужно отслеживать и корректировать вручную.
