!! Основные возможности

* База заметок хранится в виде директорий на диске.
* Поддержка плагинов (расширений). Список плагинов можно увидеть на [[этой странице -> https://jenyay.net/Outwiker/Plugins]].
* К каждой заметке можно прикреплять любое количество файлов (см. [[Прикрепленные файлы -> page://attachments]]) и папок.
* Страницы могут быть разных типов: [[викистраницы -> page://wiki-page]], [[HTML-страницы -> page://html-page]], простые [[текстовые страницы -> page://text-page]]. С помощью плагинов могут быть добавлены другие типы страниц. Например, существует [[плагин -> https://jenyay.net/Outwiker/Markdown]] для создания страниц в формате Markdown.
* [[Прикрепленные картинки -> page://attachments]] могут быть вставлены в HTML- и викистраницы.
* Раскраска синтаксиса HTML.
* Поддержка [[меток -> page://tags]] для заметок.
* Групповое добавление, удаление и переименование меток.
* Поддержка закладок на заметки.
* Значки для заметок.
* Возможность создания ссылок между страницами.
* Глобальный [[поиск -> page://search-page]] по заметкам и поиск по меткам.
* Каждая ветвь дерева может быть открыта как отдельная база заметок.
* Программа распространяется с открытыми исходниками.
* Кроссплатформенность (поддержка Windows и Linux).
* Портабельность. Программа все настройки может хранить рядом с запускаемым файлом.
