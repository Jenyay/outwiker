!! Страницы поиска


Глобальный поиск по заметкам в реализован в виде отдельного [[типа страниц -> page://page-types]], которые могут располагаться в дереве где угодно. Обычно логичнее всего было бы создавать такие страницы на самом верхнем уровне иерархии дерева заметок. Можно создавать несколько страниц поиска. Такое представление поиска может быть удобно, если вы часто используете одни и те же критерии для поиска заметок. В этом случае каждая страница настроена на свой критерий поиска, который сохраняется между перезапусками программы.

%center%%thumb width=600%Attach:outwiker_search.png%% 

Создавать страницу поиска можно создавать разными способами. Такую страниц можно создать, как и любую другую страницу с помощью кнопок над деревом заметок или с помощью пункта меню %notice%Дерево - Создать страницу того же уровня...%% или %notice%Дерево - Создать дочернюю страницу...%% В этом случае в открывшемся диалоге %notice%Создать страницу%% в выпадающем списке %notice%Тип страницы%% нужно выбрать %notice%Страница поиска%%.

%center%Attach:dialog.png

Также существует упрощенный способ создания страницы поиска. При выборе пункта меню %notice%Инструменты – Глобальный поиск…%% или при нажатии соответствующей кнопки на панели инструментов будет создана и сразу выбрана страница поиска с именем %notice%[=# Поиск=]%%. Если страница поиска с таким именем уже была создана, то при выборе этого пункта меню программа переключится на эту страницу.

Искать заметки можно как по содержимому страницы, так и по тегам. Если в поле %notice%Фраза для поиска%% не вводить искомую фразу, то поиск будет осуществляться только по тегам, причем можно выбирать, страница должна содержать все отмеченные теги или хотя бы один из них.

Если никакие теги не отмечены, то при поиске теги не будут учитываться. Если оставить пустым поле для искомой фразы и не отметить ни одного тега, то будут выведены все страницы в дереве.
