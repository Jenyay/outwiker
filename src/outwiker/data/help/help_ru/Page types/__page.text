!! Типы страниц

Страницы в OutWiker могут быть разных типов. На данный момент имеются следующие типы страниц:

* [[Вики-страница -> page://wiki-page]]. Наиболее богатый функционалом тип страниц. Именно этот тип рекомендуется использовать в большинстве случаев.
* [[HTML-страница -> page://html-page]]. Тип страницы, на которой оформление заметок осуществляется добавлением тегов HTML. Этот тип страниц может быть полезен, если вы готовите статьи для публикации на веб-сайте.
* [[Текстовая страница -> page://text-page]]. Самый простой тип страниц, который не поддерживает никакое форматирование. Только текст и больше ничего.
* [[Страница поиска -> page://search-page]]. Это особый тип страниц, предназначенный для поиска текста по всему дереву заметок и сохранение результата поиска.

Также с помощью [[плагинов -> page://plugins]] можно добавлять другие типы страниц. В частности:

* Плагин [[Markdown -> https://jenyay.net/Outwiker/Markdown]] добавляет тип страницы, для форматирования которой используется разметка Markdown.
* Плагин [[WebPage -> https://jenyay.net/Outwiker/WebPage]] позволяет скачивать страницы веб-сайтов и сохраняет результат в виде страниц собственного типа.
