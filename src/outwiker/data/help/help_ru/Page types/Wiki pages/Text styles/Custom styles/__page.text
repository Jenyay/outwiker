!! Пользовательские стили оформления текста

Если вы знакомы с языком CSS, то можете создавать собственные [[стили оформления текста -> page://textstyles]], которые затем можно будет использовать на викистраницах с помощью команды %code%[=%your-style%Текст с оформлением%%=]%%.

Все стили оформления хранятся в поддиректории %notice%textstyles%% в [[директории настроек -> page://config-dirs]]. Строковые стили хранятся в поддиректории %notice%textstyles/inline%%, а блоковые - в папке %notice%textstyles/block%%.

Чтобы добавить новый стиль, в одной из перечисленных директорий нужно создать файл с расширением %notice%.css%%, а имя этого файла должно соответствовать имени создаваемого стиля. Например, если вы хотите создать новый ''блоковый'' стиль %notice%my-cool-style%%, то вы должны создать файл %notice%my-cool-style.css%% в директории %notice%textstyles/block%%. Если вы хотите создать одноименный строковый стиль, то вы должны создать файл %notice%my-cool-style.css%% в директории %notice%textstyles/inline%%.

Созданный файл должен содержать код CSS, который будет вставлен в код викистраницы. При этом нужно учитывать, что строковые стили будут применяться к тегу %code%&lt;span&gt;%%, а блоковые - к тегу %code%&lt;div&gt;%%. Поэтому строковый стиль %notice%my-cool-style%% должен содержать код:

%code%
[@span.my-cool-style {
...
}@]
%%

а блоковый стиль с тем же именем должен содержать код:

%code%
[@div.my-cool-style {
...
}@]
%%

В частности, для создания стиля %notice%object%% нужно создать в директории %notice%textstyles/inline%% файл %notice%object.css%%, например, с таким содержимым:

%code%
[@span.object {
    display: inline;
    background-color: #ffd180;
    color: inherit;
    padding: 0px 2px;
    border-radius: 1px;
}@]
%%

После этого новый стиль %notice%object%% можно будет использовать следующим образом:

%border%
Обычный текст. %code%[=%object%Текст со стилем "object"%%=]%%. Опять обычный текст.
%%

Также в файл стиля можно добавлять произвольный CSS-код, который также будет вставлен в HTML-код викистраницы.
