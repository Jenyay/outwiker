!! Команда [=(:attachlist:)=]

!!! [[#syntax]] Назначение и синтаксис
[[Викикоманда -> page://wikicommand]] %code%[=(:attachlist:)=]%% предназначена для вставки в викистраницу списка [[прикрепленных файлов -> page://wiki-attachments]]:

%code%[=(:attachlist [params...]:)=]%%

Дополнительно в команде %code%[=(:attachlist:)=]%% могут быть использованы следующие параметры:

* %code%sort%% - указывает порядок сортировки файлов. Этот параметр может принимать следующие значения:
** [-] %code%name%% - прикрепленные файлы будут отсортированы по именам (это значение по умолчанию и равносильно использованию команды %code%[=(:attachlist:)=]%% без параметров);
** [-] %code%descendname%% - прикрепленные файлы будут отсортированы по именам в обратном порядке;
** [-] %code%ext%% - прикрепленные файлы будут отсортированы по расширениям;
** [-] %code%descendext%% - прикрепленные файлы будут отсортированы по расширениям в обратном порядке;
** [-] %code%size%% - прикрепленные файлы будут отсортированы по их размеру;
** [-] %code%descendsize%% - прикрепленные файлы будут отсортированы по их размеру в обратном порядке;
** [-] %code%date%% - прикрепленные файлы будут отсортированы по дате их последней модификации;
** [-] %code%descenddate%% - прикрепленные файлы будут отсортированы по дате их последней модификации в обратном порядке;

* %code%subdir%% - позволяет отображать прикрепленные файлы из вложенных папок.


!!! [[#examples]] Примеры
У данной страницы имеется пять вложенных файлов, а также директория %notice%subfolder%% с еще несколькими файлами. Далее показан результат работы команды %code%[=(:attachlist:)=]%% с различными значениями параметров:
