!! Команда [=(:childlist:)=]

!!! [[#syntax]] Назначение и синтаксис

Команда %code%[=(:childlist:)=]%% предназначена для отображения на вики-странице списка дочерних страниц. Синтаксис команды следующий:

%code%
[=(:childlist [sort=...]:)=]
%%

Необязательный параметр %code%sort%% устанавливает порядок отображения дочерних страниц. Если параметр %code%sort%% не указан, то страницы будут выводиться в том же порядке, как они расположены в дереве заметок.

Параметр %code%sort%% может принимать следующие значения:

* %code%name%% - дочерние страницы в выводимом списке будут отсортированы по алфавиту;
* %code%descendname%% - дочерние страницы в выводимом списке будут отсортированы по алфавиту в обратном порядке;
* %code%creation%% - дочерние страницы в списке будут отсортированы по дате создания (самые старые страницы будут располагаться сверху);
* %code%descendcreation%% - дочерние страницы в списке будут отсортированы по дате создания (самые новые страницы будут располагаться сверху);
* %code%edit%% - дочерние страницы в списке будут отсортированы по дате последней правки (страницы, редактированные последними, будут располагаться внизу);
* %code%descendedit%% - дочерние страницы в списке будут отсортированы по дате последней правки (страницы, редактированные последними, будут располагаться сверху);
* %code%descendorder%% - дочерние страницы в выводимом списке будут иметь порядок, противоположный порядку следования страниц в дереве;


!!! [[#examples]] Примеры
 
У данной страницы имеются четыре дочерние страницы, следующая таблица показывает результат работы команды %code%[=(:childlist:)=] %%с различными значениями параметра %code%sort%%:

||width=100% border=1 style="border-collapse: collapse; border: 1px solid black;"
|| '''Команда''' || %code%[=(:childlist:)=]%% || %code%[=(:childlist sort=name:)=]%% || %code%[=(:childlist sort=descendname:)=]%% || %code%[=(:childlist sort=descendorder:)=]%% ||
|| '''Результат''' ||(:childlist:) ||(:childlist sort=name:) ||(:childlist sort=descendname:) ||(:childlist sort=descendorder:) ||
