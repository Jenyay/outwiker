!! Ссылки

Текст вики-страниц может содержать ссылки на сайты в интернете, а также на другие страницы дерева заметок.Такие ссылки можно создавать несколькими разными способами. В следующей таблице приведены примеры оформления таких ссылок.

||%code%[=[[https://example.com]]=]%%||[[https://example.com]]||Ссылка на адрес в интернете||
||%code%[=[[Пример ссылки -> https://example.com]]=]%%||[[Пример ссылки -> https://example.com]]||Ссылка на адрес в интернете с заданным текстом||
||%code%[=[[https://example.com | Пример ссылки]]=]%%||[[https://example.com | Пример ссылки]]||Ссылка на адрес в интернете с заданным текстом||
