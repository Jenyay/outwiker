!! Викистраница

Этот [[тип страниц -> page://page-types]] имеет наибольшее количество возможностей для форматирования текста с помощью различных викикоманд, но при этом остается возможность вставлять "сырой" код HTML, если возможностей викинотации не хватает для каких-то задач. Но в первую очередь викистраницы рассчитаны на использование синтаксиса, напоминающий (но не точно копирующий) нотацию, которая используется в [[pmWiki -> https://pmwiki.org/]].

Более подробно синтаксис викинотации описывается во вложенных страницах справки:

(:childlist:)
