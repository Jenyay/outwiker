Подходы для создания таблиц


Для создания таблиц на викистраницах существует подхода:
  • использование упрощенной викинотации для создания небольших таблиц;
  • использование викикоманды (:table:)...(:tableend:) с возможностью более тонкой настройки внешнего вида таблиц.
Далее будут рассмотрены оба подхода.

Упрощенное создание таблиц


Для создания таблиц с помощью упрощенной викинотации используется следующий формат записи:

|| Параметры таблицы
|| Первая ячейка первой строки || Вторая ячейка первой строки || ... || Последняя ячейка первой строки ||
|| Первая ячейка второй строки || Вторая ячейка второй строки || ... || Последняя ячейка второй строки ||
...


При использовании такой нотации обязательно нужно объявить начало таблицы с помощью символов ||, после которых могут быть казаны или не указаны параметры таблицы, которые представляют собой атрибуты HTML-тега <table>), например, border, width и т.п. Затем каждая новая строка, начинающаяся с символов ||, описывает каждую строку таблицы. Ячейки таблицы также разделяются с помощью символов ||. Эти же символы ставятся в конце каждой строки таблицы.

Горизонтальное выравнивание текста в ячейках таблицы задается пробелами перед и после текста внутри ячейки. Это показано на следующем примере:

Код таблицы:

|| border=1 width=100%
||Выравнивание по левому краю || Выравнивание по центру || Выравнивание по правому краю||


Результат:

Выравнивание по левому краю Выравнивание по центру Выравнивание по правому краю

Использование команды (:table:)

Синтаксис


С помощью викикоманды (:table:) удобнее создавать большие таблицы в форматированием текста внутри ячеек. Синтаксис этой команды следующий:

(:table параметры:)
(:row параметры:)
(:hcell параметры:) Текст заголовочной ячейки
(:hcell параметры:) Текст заголовочной ячейки
...
(:row параметры:)
(:cell параметры:) Текст ячейки
(:cell параметры:) Текст ячейки
...
(:tableend:)

В команде (:table:) могут использоваться те же параметры, что и в теге <table> языка HTML. Наиболее часто используемые параметры - это :
  • border для задания толщины рамки таблицы. Усли border=0, что является значением по умолчанию для команды, то таблица отображается без рамки.
  • width для задания ширины таблицы.
  • align для задания выравнивания таблицы.
Команда (:table параметры:)...(:tableend:) преобразуется в HTML-код вида: <table параметры>...</table>.

Команда (:row:) указывает на начало новой строки таблицы, она является аналогом HTML-тега <tr> и, соответственно, может содержать в себе те же самые параметры.

Начало новой ячейки задается с помощью команд (:cell:) для обычных ячеек или (:hcell:) для заголовочных ячеек. Команда (:cell:) является аналогом HTML-тега <td>, а команда (:hcell:) - аналогом HTML-тега <th>.

Вложенные таблицы


Чтобы одна таблица располагалась в ячейке другой таблицы, недостаточно одной команды (:table:), в этом случае википарсер не будет знать, где заканчивается таблица верхнего уровня, а где вложенная таблица, поэтому для явного указания начала и конца команды создания таблицы были добавлены команды (:table:) с номерами: (:table1:), (:table2:), (:table3:), (:table4:) и (:table5:). Они могут использоваться точно также, как и команда (:table:), но создавались они именно для создания вложенных таблиц. В соответствии с правилами форматирования викикоманд, перечисленные нумерованные команды закрываются с помощью выражений (:table1end:), (:table2end:), (:table3end:), (:table4end:) и (:table5end:) соответственно.

Внутри команды вида (:tableN:) (где N = 1, 2, ..., 5) для создания строк и ячеек должны использоваться также нумерованные команды (:rowN:), (:cellN:) и (:hcellN:). Эта особенность добавляет наглядности, какой именно таблице какая строка или ячейка принадлежит.
