!!! [[#intro]] Общие сведения

С помощью викинотации можно создавать нумерованные и ненумерованные списки. Для создания ненумерованных списков используется один или несколько символов %code%[=*=]%%, стоящие в начале строки. При увеличении количества символов %code%[=*=]%%, расположенных подряд без пробелов, увеличивается уровень вложенности элемента списка.

Аналогично для создания нумерованных списков используется один или несколько символов %code%[=#=]%%, стоящие в начале строки.

Для создания ненумерованного списка можно воспользоваться пунктом меню %notice%Вики - Списки - Ненумерованный список%% или кнопкой Attach:bullet.png.

Для создания нумерованного списка можно воспользоваться пунктом меню %notice%Вики - Списки - Нумерованный список%% или кнопкой Attach:order.png.

Если курсор стоит на строке, которая уже является элементом списка (строка начинается с символа %code%[=*=]%% или %code%[=#=]%%), то нажатие кнопок Attach:bullet.png и Attach:order.png или выбор соответствующих им пунктов меню увеличивает уровень вложенности элемента списка.

Далее приведены несколько примеров использования списков в викинотации.

!!! [[#styles]] Стили списков

Для ненумерованных списков можно изменять стиль буллетов - так в издательском деле называют значки, которые ставят в начале каждого пункта списка. Это может быть полезно, например, для оформления списка дел, тогда предстоящие дела можно помечать одним стилем, а выполненные дела - другим (для этого предусмотрены специальные стили). Стили списков полезны, если вы используете методологию ведения списков [[Bullet Journal -> https://en.wikipedia.org/wiki/Bullet_journal]].

Стиль указывается после символа %code%[=*=]%% ненумерованного списка и представляет собой комбинацию квадратных скобок, между которыми может быть дополнительный символ, определяющий стиль. В следующей таблице перечислены поддерживаемые на данный момент стили:

(:table border="1" width=600em style="border-collapse: collapse; border: 1px solid black;":)
(:row:)
(:hcell:) Викинотация
(:hcell:) Результат
(:row:)
(:cell:)%code%[=* [ ] Первый элемент списка
* [ ] Второй элемент списка=]%%
(:cell:)
* [ ] Первый элемент списка
* [ ] Второй элемент списка

(:row:)
(:cell:)%code%[=* [/] Первый элемент списка
* [/] Второй элемент списка=]%%
