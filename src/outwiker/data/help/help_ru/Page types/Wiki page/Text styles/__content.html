Синтаксис для установки стиля

Для оформления текста на викистраницах предусмотрена специальная команда для установки стиля текста (не путать со стилями страницы). Общий формат команды для установки стиля выглядит следующим образом: %параметры%текст%%. Эту команду можно применять для оформления блока текста (блоковый стиль) или текста внутри абзаца (строчный стиль).

Блоковый стиль задаётся с помощью команды

%параметры%
текст с оформлением
%%

Важно, чтобы строки %параметры стиля% и %% начинались с начала строки, то есть перед ними не должно быть пробелов.

Строчный стиль задаётся с помощью конструкции, которая может быть использована внутри текста.

%параметры%текст%%


Внутри строчной команды %...%...%% не должно быть переносов строк за исключением команды [[<<]]. Блоковый стиль может содержать множество строк и абзацев.

В обоих форматах команд параметры стиля могут содержать следующие элементы:
  • Имя стиля.
  • Цвет текста.
  • Цвет фона.
  • Собственные настройки стиля.
  • Комбинацию всего вышеперечисленного.

Именованные стили

Программа OutWiker содержит множество встроенных строчных и блоковых стилей, их полный список можно увидеть в диалоге для выбора стиля (пункт меню Вики - Форматирование - Стиль текста...) или в разделе Встроенные стили и цвета.

Например:

Викинотация Результат
Обычный текст. %notice%Текст со стилем notice%%. Опять обычный текст. Обычный текст. Текст со стилем notice. Опять обычный текст.

Установка цвета текста

Вместо имени стиля можно указывать цвета - по имени или в форматах#RRGGBB, #RGB, rgb(r,g,b). Список встроенных имён цветов приводится в разделе Встроенные цвета.

Например:

Викинотация Результат
Обычный текст. %blue%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.
Обычный текст. %#A2F%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.
Обычный текст. %#15acac%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.


Также цвет можно задавать с помощью параметра color:

Викинотация Результат
Обычный текст. %color=blue%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.
Обычный текст. %color="#A2F"%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.
Обычный текст. %color="#15acac"%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.
Обычный текст. %color="rgb(200, 90, 128)"%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.

Установка цвета фона

Для установки цвета фона части строки или блока предусмотрено несколько вариантов.

Если вы ходите установить в качестве цвета фона один из стандартных именованных цветов, то достаточно указать имя цвета, добавив приставку bg_ или bg-. Например:

Викинотация Результат
Обычный текст. %bg-yellow%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.
Обычный текст. %bg_aqua%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.

Также для указания цвета фона можно использовать параметр bgcolor, который позволяет устанавливать цвета не только по имени, но также использовать формат #RGB, #RRGGBB и rgb(r,g,b):

Викинотация Результат
Обычный текст. %bgcolor="#AB6"%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.
Обычный текст. %bgcolor="#AA66CC"%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.
Обычный текст. %bgcolor="rgb(200, 90, 128)"%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.

Дополнительные настройки стиля


Вы можете применить к участку текста или блоку произвольный стиль CSS с помощью параметра style.

Например:

Викинотация Результат
Обычный текст. %style="font-weight: bold; border: 1px solid;"%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.

Комбинация всего вышеперечисленного


Все параметры, которые были были указаны выше могут быть использованы одновременно. Также к тексту можно применять несколько стилей.

Например:

Викинотация Результат
Обычный текст. %blue bg-yellow style="font-weight: bold; border: 1px solid;"%Текст со стилем%%. Опять обычный текст. Обычный текст. Текст со стилем. Опять обычный текст.
