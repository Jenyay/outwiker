<h1>HTML-страницы</h1>

Одним из типов страниц, поддерживаемый OutWiker-ом, являются страницы, на которых для оформления текста используется язык разметки HTML. Если при открытии <a href="page://wiki-page">вики-страницы</a> кнопки на панели инструментов вставляют в текст викиразметку, то на HTML-страницах аналогичные кнопки добавляют соответствующие HTML-теги. 

HTML-страницы могут стать полезным инструментом для подготовки публикаций на веб-сайт. 

На панель инструментов HTML-страницы вынесены кнопки для добавления некоторых наиболее часто используемых тегов. Но помимо HTML-тегов, которые можно вставлять с помощью кнопок на панели инструментов (или меню), в HTML-страницы можно добавлять любые теги, которые поддерживает веб-движок, на основе которого работает OutWiker. На данный момент под Windows для показа HTML-страниц используется движок Internet Explorer, а под Linux - WebKit. 

Поскольку на HTML-странице могут быть использованы любые HTML-теги, включая &lt;script&gt;, нужно с подозрением относиться к тем заметкам, которые вы получили от сторонних источников. 

В отличие от стандартного HTML-кода, OutWiker учитывает перевод строк. Каждый перевод строки заменяется на тег &lt;br&gt;.

На HTML-страницах так же можно добавлять ссылки на другие страницы, используя для этого тег &lt;a&gt;. Ссылки можно создавать на страницы по их относительынм путям в дереве заметок или, что более предпочтительно, идентификаторам (например, <a href="page://__a31ba2cf-93a2-4ed1-b3a3-116104c171e2">page://__a31ba2cf-93a2-4ed1-b3a3-116104c171e2</a>). Более подробно про ссылки описано на странице <a href="page://links">Ссылки на страницы</a>.

На странице возможны ссылки на прикрепленные файлы. Примеры смотрите ниже.

При написании заметки на HTML-странице вам не требуется оформлять полностью HTML-документ, вы вводите только текст, который находится внутри тега &lt;body&gt;...&lt;/body&gt;. Заголовки HTML-документа, которые указываются внутри тега &lt;head&gt;...&lt;/head&gt;, формируются автоматически на основе <a href="page://styles">стиля страницы</a>.
