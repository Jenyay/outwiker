Текстовые страницы - это самый простой тип страниц. Такие страницы не позволяют использовать никакое оформление текста, вставлять картинки и ссылки. Однако, как и все другие страницы, текстовые страницы позволяют хранить прикрепленные файлы.

Такой тип страниц может быть полезен, если вы любите минимализм и вам хотелось бы в первую очередь писать текст, не отвлекаясь на оформление. В некоторых случаях текстовые заметки удобно использовать для хранения шаблонов и блоков кода для различных языков программирования.
