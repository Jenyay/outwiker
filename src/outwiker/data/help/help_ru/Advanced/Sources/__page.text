!! Запуск из исходников

OutWiker является программным обеспечением со свободным исходным кодом, который распространяется по лицензии GPL 3. Если вы хотите получить исходный код и запустить OutWiker из исходников, следуйте описанной ниже процедуре. Для запуска потребуется Python 3.8 - 3.12. При попытке использовать более новые версии Python возникнут проблемы с некоторыми библиотеками. Для создания виртуальных окружений рекомендуется использовать [[uv -> https://docs.astral.sh/uv/]].

Для получения исходных кодов и создания виртуального окружения выполните в консоли следующие команды:

%code%
git clone https://github.com/Jenyay/outwiker
cd outwiker
uv sync --dev --extra gui --python 3.12
%%

В некоторых дистрибутивах Linux может возникнуть проблема с последней командой в процессе установки библиотеки wxPython. В этом случае рекомендуется установить wxPython вручную из wheel, которые можно найти [[по ссылке -> https://extras.wxpython.org/wxPython4/extras/linux/gtk3/]]. В данной версии используется wxPython 4.2.5.

Для запуска OutWiker выполните следующую команду:

%code%
uv run python -m outwiker
%%

В git-репозитории с исходными кодами используются следующие ветки:

* %notice%master%% - текущая бета-версия.
* %notice%dev%% - текущая разрабатываемая версия. Перед выходом очередной бета-версии эта ветвь будет влита в ветвь master.
* %notice%stable%% - текущая стабильная версия.

Также каждая стабильная и бета-версия помечаются соответствующими тегами.
