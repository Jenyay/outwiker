!! Параметры командной строки

При запуске OutWiker из командной строки приложению можно указать дополнительные параметры. Далее перечислены, какие именно параметры поддерживаются в данной версии.

Формат передачи параметров через командную строку следующий:

%code%
[=outwiker [--page PAGE] [--help] [--version] [--readonly] [--normal] [--debug] [--disable-plugins] [path]=]
%%

Здесь квадратные скобки %code%[=[...]=]%% обозначают необязательную часть. Далее описан каждый из параметров.

* %code%path%% - путь до дерева заметок. При указании этого параметра OutWiker сразу откроет дерево заметок по указанному пути. В качестве этого параметра может быть указан путь до директории, содержащей файл %info%__page.opt%% в корне дерева заметок, или путь непосредственно до этого файла. Например: 

%code%outwiker.exe "C:\temp\samplewiki"%%
%code%outwiker.exe "C:\temp\samplewiki\__page.opt"%%


* %code%-r%% или %code%--readonly%% - открыть дерево заметок в режиме "только для чтения". В этом случае невозможно изменить текст страниц, состояние дерева заметок также не сохраняется. В таком режиме, например, открывается справка по OutWiker.


* %code%-p%% или %code%--page%%. С помощью этого параметра можно указать [[идентификатор страницы -> page://links]] или относительный путь до страницы, которая должна быть открыта сразу после загрузки дерева заметок. Например:

%code%[=outwiker.exe --page="page://1640eea0-1bb0-453b-ba4c-07f1c298ce76" "C:\temp\samplewiki"=]%%
%code%outwiker.exe --page="Страница 1/Страница 2/Страница 3" "C:\temp\samplewiki"%% 
%code%outwiker.exe -p "Страница 1/Страница 2/Страница 3" "C:\temp\samplewiki"%% 

* %code%--normal%% - не минимизировать главное окно OutWiker при запуске, даже если в настройках указано, что при запуске окно программы должно быть свернуто [[в трей -> page://settings_interface_tray]].


* %code%--debug%% - запуск в режиме отладки. В этом случае в файл %info%outwiker.log%% в [[директории настроек -> page://config-dirs]] будет добавляться множество дополнительной информации, помогающей отследить работу приложения. При частом использовании этого параметра файл %info%outwiker.log%% может быстро увеличиваться в размерах. Без этого параметра по умолчанию в файл %info%outwiker.log%% записываются только сообщения о возникающих ошибках и предупреждения.


* %code%--disable-plugins%% - при запуске приложения деактивировать все установленные [[плагины -> page://plugins]].


* %code%-h%% или %code%--help%% - показать справку по параметрам командной строки.


* %code%-v%% или %code%--version%% - показать номер версии OutWiker.
