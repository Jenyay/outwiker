!! Изменение типа страниц

OutWiker поддерживает разные [[типы страниц -> page://page-types]]: простые [[текстовые страницы -> page://text-page]], [[HTML- -> page://html-page]] и [[викистраницы -> page://wiki-page]], а также [[страницы глобального поиска -> page://search-page]]. Кроме того некоторые плагины, например, [[Markdown -> https://jenyay.net/Outwiker/Markdown]] и [[WebPage -> https://jenyay.net/Outwiker/WebPage]], добавляют новые типы страниц. 

В данный момент после создания страницы нет возможности изменить ее тип через графический интерфейс. Однако тип страницы можно изменить, отредактировав содержимое файла %info%__page.opt%% внутри директории страницы. Для этого указанный файл нужно открыть в текстовом редакторе и внутри секции %code%[General]%% изменить значение параметра %code%type%%. Возможные значения этого параметра перечислены далее. Это список поддерживаемых в данный момент встроенных типов страниц:

* %code%text%% - [[Текстовая страница -> page://text-page]]
* %code%html%% - [[HTML-страница -> page://html-page]], 
* %code%wiki%% - [[Wiki-страница -> page://wiki-page]] 
* %code%search%% - [[Страница поиска -> page://search-page]]

Типы страниц, поддерживаемые с помощью плагинов:

* %code%markdown%% - страница в формате Markdown (плагин [[Markdown -> https://jenyay.net/Outwiker/Markdown]])
* %code%web%% - веб-страница (плагин [[WebPage -> https://jenyay.net/Outwiker/WebPage]]).

Если вы редактируете файл настроек страницы, открытого в данный момент дерева заметок, не забудьте перезагрузить дерево заметок.

%warn%
Изменять тип страниц следует с осторожностью, потому что для разных типов страниц файл %info%__page.opt%% может содержать различные параметры, а также может отличаться содержимое файла %info%__page.text%%.
%%
