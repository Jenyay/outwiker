Изменение типа страниц


OutWiker поддерживает разные типы страниц: простые текстовые страницы, HTML- и викистраницы, а также страницы глобального поиска. Кроме того некоторые плагины, например, Markdown и WebPage, добавляют новые типы страниц.

В данный момент после создания страницы нет возможности изменить ее тип через графический интерфейс. Однако тип страницы можно изменить, отредактировав содержимое файла __page.opt внутри директории страницы. Для этого указанный файл нужно открыть в текстовом редакторе и внутри секции [General] изменить значение параметра type. Возможные значения этого параметра перечислены далее. Это список поддерживаемых в данный момент встроенных типов страниц:
  • text - Текстовая страница
  • html - HTML-страница,
  • wiki - Wiki-страница
  • search - Страница поиска
Типы страниц, поддерживаемые с помощью плагинов:
  • markdown - страница в формате Markdown (плагин Markdown)
  • web - веб-страница (плагин WebPage).
Если вы редактируете файл настроек страницы, открытого в данный момент дерева заметок, не забудьте перезагрузить дерево заметок.

Изменять тип страниц следует с осторожностью, потому что для разных типов страниц файл __page.opt может содержать различные параметры, а также может отличаться содержимое файла __page.text.
