!! Структура дерева заметок

Дерево заметок (страниц) строится на основе дерева файловой системы. Каждая страница расположена в своей отдельной директории, а вложенные поддиректории образуют дочерние страницы.

В каждой директории, чтобы она считалась страницей с заметками, а также в корне дерева, должен присутствовать файл %info%__page.opt%%, в котором хранятся свойства данной заметки ([[тип заметки -> page://page-types]], [[теги -> page://tags]] и другая информация). Содержимое этого файла зависит от [[типа страницы -> page://page-types]]. Кроме того в директориях с заметками может быть расположен файл %info%__page.text%% – собственно, содержимое заметки (формат этого файла тоже зависит от типа страницы) и, возможно, файл %info%__icon.*%% - иконка для заметки в любом графическом формате (обычно в формате SVG или PNG).

Внутри директорий [[вики- -> page://wiki-page]] и [[HTML-страниц -> page://html-page]] создается файл %info%__content.html%%, который содержит окончательный вид заметки, который показывается пользователю. Этот файл создается на основе викинотации или HTML-кода, который вводит пользователь при написании заметки. Если вам нужно открыть заметку на компьютере, где не установлен OutWiker, то вы можете открыть файл %info%__content.html%% нужной заметки в любом браузере.

В каждой директории-заметке может быть поддиректория %info%__attach%%, куда помещаются [[прикрепленные файлы -> page://attachments]]. Эта директория создается только при необходимости, если пользователь добавляет вложение на страницу или копирует путь до директории с вложениями через контекстное меню в дереве заметок или с помощью пункта меню %notice%Инструменты - Пути - Копировать путь до вложений%%. Для того, чтобы прикрепить файл к заметке, достаточно его скопировать в директорию %info%__attach%%. Внутри этой директории можно создавать вложенные директории, которые также будут отображаться на панели %notice%Вложения%%.

В директории заметки в формате [[викинотации -> page://wiki-page]] может присутствовать директория с именем %info%__thumb%%. Изначально она была предназначена для хранения миниатюр изображений, но также эту директорию иногда используют для хранения дополнительных файлов, используемых при отображении сгенерированного HTML-кода.

По умолчанию  имя заметки совпадает с именем директории, содержащей эту заметку. При этом все директории, имена которых начинаются с двух символов подчеркивания %code%__%%, считаются служебными и не рассматриваются как вложенная страница. Однако это не значит, что имена заметок не могут начинаться с этих символов. Чтобы обойти такое ограничение, можно использовать [[псевдонимы страниц -> page://advanced-aliases]], позволяющие создавать заметки, имена которых не совпадают с именами директорий, которые эти заметки содержат. Также это позволяет обойти ограничения файловых систем на использование некоторых символов в именах файлов и директорий.

В корневой директории дерева заметок создается файл %info%__cache.tmp%%, который содержит вспомогательную информацию, не являющейся ценной. Например, в этом файле содержится информация о том, какая ветвь дерева заметок является раскрытой в данный момент, а какая - закрытой. Потеря информации из этого файла не является проблемой, и поэтому файл %info%__cache.tmp%% можно не хранить на сервере или в репозитории, если вы используете для хранения дерева заметок системы контроля версий.

Благодаря такой структуре возможно открывать каждую ветвь дерева как отдельное дерево заметок, только при этом надо учитывать, что корневой элемент древа не содержит текста заметки, а используется только как контейнер для вложенных страниц.
