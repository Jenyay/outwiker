!! Вики-страница

%center%Attach:outwiker_opt_wikipage.png

Данный раздел содержит параметры, влияющие на внешний вид [[вики-страниц -> page://wiki-page]]. 

Во время переключения вики-страницы в режим %notice%Просмотр%% в фоне происходит генерация кода для создания HTML-страницы. Именно эта HTML-страница затем отображается пользователю. В большинстве случаев о том, как выглядит полученный HTML-код можно не задумываться. Однако для некоторых задач может оказаться полезен созданный по викинотации HTML-код. Например, если вы используете OutWiker для создания страниц сайта или постов для блога. Для этого служит режим %notice%HTML%%, вкладка которого располагается внизу, рядом со вкладкой %notice%Просмотр%%. Поскольку этот режим нужен далеко не всем, то по умолчанию вкладка для переключения в этот режим скрыта. Чтобы ее показать, нужно установить флажок %notice%Показывать вкладку с кодом HTML%%.

С помощью флажка %notice%Раскрашивать викинотацию%% можно включать или отключать подсветку синтаксиса на странице с викинотацией.

С помощью параметра %notice%Размер миниатюр%% можно установить размер по умолчанию для уменьшенных изображений, которые будут создаваться с помощью синтаксиса [[[=%thumb%Attach:имя_файла%%=] -> page://wiki-attachments/#thumb]] при условии, если размер миниатюры не задан явным образом с помощью дополнительного параметра этого викитега.

[[Ссылки ->page://wiki-links]] на вики-страницах могут быть представлены в двух форматах:

* %code%[=[[Ссылка -> Комментарий]]=]%%
* %code%[=[[Комментарий | Ссылка]]=]%%

При использовании диалога, вызываемого с помощью пункта меню %notice%Вики - Ссылка%% или соответствующей кнопки на панели инструментов, ссылка может создаваться и в том, и в другом формате. Какой из этих форматов будет использован, задается с помощью параметра %notice%Стиль ссылок по умолчанию%%.

Если вы создадите [[вики-страницу -> page://wiki-page]] и оставите ее содержимое пустой (не должно быть даже пробелов), то при переключении в режим %notice%Просмотр%% вместо белого листа можно увидеть что-то более полезное. Например, по умолчанию будет отображаться список прикрепленных файлов и список дочерних страниц. Это поведение можно изменить с помощью параметра %notice%Шаблон для пустой страницы%%. Текст этого поля ввода будет использоваться вместо содержимого пустой страницы. Шаблон пустой страницы может содержать викинотацию.
