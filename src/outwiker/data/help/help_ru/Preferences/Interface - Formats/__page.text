!! Интерфейс - Форматы

%center%Attach:outwiker_opt_formats.png

Поле ввода %notice%Формат даты и времени%% позволяет задать формат, в котором будут отображаться даты создания и редактирования страниц в различных частях программы, например, в статусной панели. OutWiker использует формат даты и времени, [[применяемый в языке Python -> https://docs.python.org/2/library/datetime.html#strftime-and-strptime-behavior]]. Запоминать символы форматирования не требуется, поскольку справа от поля ввода есть кнопка, при нажатии на которую будет открыто меню, содержащее все возможные элементы данного формата. Под полем ввода отображается пример оформления даты и времени согласно выбранному формату.

Поле ввода %notice%Шаблон заголовка новой страницы%% позволяет задать имя страницы по умолчанию при ее создании. Это удобно, если вы часто создаете страницы, заголовки которых содержат, например, текущую дату или время. В этом поле ввода можно использовать те же элементы подстановки, что и для поля ввода %notice%Формат даты и времени%%, описанный выше.
