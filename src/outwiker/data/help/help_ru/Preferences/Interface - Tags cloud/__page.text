!! Интерфейс - Облако меток

%center%Attach:outwiker_opt_tags.png

Этот раздел содержит настройки для изменения внешнего вида панели %notice%Метки%%.

%center%Attach:tags_cloud.png 

Эта панель отображает облако меток, шрифт для каждой метки тем крупнее, чем к большему количеству заметок применена метка. С помощью полей ввода %notice%Минимальный размер шрифта%% и %notice%Максимальный размер шрифта%% можно настроить диапазон изменения размера шрифта в облаке меток. Если вам не нравится, что какие-то метки отображаются более мелко, а какие-то более крупно, вы можете установить одинаковый размер шрифта с помощью этих настроек.

Облако меток может отображаться в двух режимах, которые переключаются с помощью выпадающего списка %notice%Режим отображения облака меток%%:
* Режим %notice%Непрерывный текст%% используется по умолчанию и в этом режиме на одной строке в облаке меток отображается несколько меток.
* Режим %notice%Список%% отображает метки по одной на строку.

С помощью флажка %notice%Показывать всплывающие подсказки%% можно включать или отключать подсказки, появляющиеся при наведении курсора мыши на метку. Такие подсказки содержат информацию о количестве заметок, которые содержат данную метку.

Далее с помощью группы флажков %notice%Заголовки во всплывающем окне%% можно включать и отключать заголовки в окне, которое появляется при клике на метку.
