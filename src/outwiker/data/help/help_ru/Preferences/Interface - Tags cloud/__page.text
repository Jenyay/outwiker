!! Интерфейс - Облако тегов

%center%Attach:outwiker_opt_tags.png

Этот раздел содержит настройки для изменения внешнего вида панели %notice%Теги%%.

%center%Attach:tags_cloud.png 

Эта панель отображает облако тегов, шрифт для каждого тега тем крупнее, чем к большему количеству заметок применён тег. С помощью полей ввода %notice%Минимальный размер шрифта%% и %notice%Максимальный размер шрифта%% можно настроить диапазон изменения размера шрифта в облаке тегов. Если вам не нравится, что какие-то теги отображаются более мелко, а какие-то более крупно, вы можете установить одинаковый размер шрифта с помощью этих настроек.

Облако тегов может отображаться в двух режимах, которые переключаются с помощью выпадающего списка %notice%Режим отображения облака тегов%%:
* Режим %notice%Непрерывный текст%% используется по умолчанию, и в этом режиме на одной строке в облаке тегов отображается несколько тегов.
* Режим %notice%Список%% отображает теги по одному на строку.

С помощью флажка %notice%Показывать всплывающие подсказки%% можно включать или отключать подсказки, появляющиеся при наведении курсора мыши на тег. Такие подсказки содержат информацию о количестве заметок, которые содержат данный тег.

Далее с помощью группы флажков %notice%Заголовки во всплывающем окне%% можно включать и отключать заголовки в окне, которое появляется при клике на тег.
