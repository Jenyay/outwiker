!! Интерфейс - Цвета

%center%Attach:outwiker_opt_colors.png

В данном разделе можно изменить цвета, используемые в интерфейсе программы. Цвета разделены на группы: %notice%Главное окно%%, %notice%Редактор%%,  %notice%Вкладки%% и %notice%Теги%%. Цвет каждого элемента интерфейса можно выбирать с помощью соответствующего выпадающего списка. При этом есть возможность использовать цвета по умолчанию, многие из которых читаются из системных настроек.

В группе %notice%Редактор%% можно изменять только цвета основных элементов редактора, которые указаны на следующей картинке:

%center%Attach:editor_colors.png

Если требуется изменить цвета раскраски синтаксиса HTML-кода или вики-страницы, то это можно сделать на странице настроек page://settings_editor_html_editor и page://settings_editor_wiki_editor соответственно.
