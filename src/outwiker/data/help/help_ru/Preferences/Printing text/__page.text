!! Печать текста

%center%Attach:outwiker_opt_print_text.png

Данный раздел позволяет настроить параметры печати [[текстовых заметок -> page://text-page]], а также [[HTML-страниц -> page://html-page]] в режиме %notice%HTML%% и [[викистраниц -> page://wiki-page]] в режимах %notice%Вики%% и %notice%HTML%%.

С помощью группы параметров %notice%Шрифт%% можно настроить размер и начертание шрифта, которым будет печататься текст.

Для печати текста заметки с оформлением используется шрифт, установленный в [[стиле страницы -> page://styles]], и поэтому данная настройка при печати оформленных заметок не используется.

После нажатия кнопки %notice% Настройки страницы...%% откроется диалог, в котором можно задать параметры страницы для печати. Внешний вид этого диалога будет различным в зависимости от операционной системы.
