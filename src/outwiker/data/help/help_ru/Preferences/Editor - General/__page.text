!!! Редактор - Общие

%center%Attach:outwiker_opt_editor_general.png

Данный раздел содержит настройки текстового редактора, который используется для ввода заметок. 

С помощью группы параметров %notice%Шрифт%% можно задавать начертание и размер шрифта.

С помощью флажка %notice%Показывать номера строк%% можно включать или отключать отображение нумерации строк слева от текста.

Ширину области с нумерацией строк можно изменять с помощью параметра %notice%Ширина поля номера строк%%. Это значение задается в пикселях. Если это значение равно 0, то ширина поля будет определяться автоматически таким образом, чтобы ширина этого поля была минимально необходимая.

Если установлен флажок %notice%Использовать пробелы вместо табуляции%%, то при нажатии клавиши %code%Tab%% в редакторе вместо символа табуляции будет вставлено несколько символов пробелов, количество которых задается в поле ввода %notice%Размер табуляции%%. По умолчанию используется 4 символа пробела.

Текстовый редактор может реагировать на нажатие клавиш %code%Home%% / %code%End%% двумя способами. При нажатии этих клавиш курсор будет перемещаться либо на начало / в конец текущей строки, либо на начало / в конец текущего абзаца (с учетом переноса строк). Это поведение переключается с помощью выпадающего списка %notice%Клавиши Home / End переносят курсор к началу / концу%%. Возможные значения этого выпадающего списка либо %notice%Строки%%, либо %notice%Абзаца%%.

В дополнение к перечисленным параметрам в разделе page://settings_interface_colors можно устанавливать цвета элементов интерфейса текстового редактора. А в разделах page://settings_editor_html_editor и page://settings_editor_wiki_editor можно также устанавливать цвета для раскраски текста HTML- и викистраниц соответственно.
