!! Интерфейс - Вкладки

%center%Attach:outwiker_opt_tabs.png

Этот раздел настроек предназначен для изменения внешнего вида вкладок, которые позволяют держать под рукой сразу несколько заметок и быстро переключаться между ними. Вкладки расположены над текстом открытой заметки.

Вкладки меняют свой размер в зависимости от их количества, при необходимости вкладки начинают занимать несколько строк.

Поле ввода %notice%Минимальная ширина вкладки%% позволяет задать горизонтальный размер в пикселях, меньше которого вкладка не будет уменьшаться при любом количестве открытых вкладок. Если вкладки с минимальным размером не будут умещаться на одной строке, они будут занимать несколько строк.

Поле ввода %notice%Максимальная ширина вкладки%% позволяет задать горизонтальный размер в пикселях, больше которого вкладки занимать не будут, даже если в строке вкладок еще имеется свободное место.

Параметры %notice%Поле по горизонтали%% и %notice%Поле по вертикали%% позволяют задать дополнительное свободное пространство по горизонтали и по вертикали соответственно внутри каждой вкладки вокруг значка и заголовка страницы.

С помощью выпадающего списка %notice%Размер шрифта%% можно изменять размер шрифта, которым отображаются заголовки заметок на вкладках. Если в этом выпадающем списке выбран пункт %notice%Размер по умолчанию%%, то будет использован размер шрифта, установленный в операционной системе для элементов интерфейса.

Флажок %notice%Отображать значки заметки%% позволяет включать и отключать отображение значка заметки на вкладках.

С помощью выпадающего списка %notice%Размер значков%% можно изменять размер значков, которые отображаются рядом с заголовком заметки на вкладке. По умолчанию используются самый мелкий размер значков - 16 x 16 пикселей. В выпадающем списке можно выбрать следующие варианты: 20 x 20, 24 x 24, 32 x 32, 48 x 48 пикселей. Это может быть полезно для мониторов с высоким разрешением.

Флажок %notice%Отображать кнопки закрытия%% позволяет включать и отключать добавление кнопок для закрытия вкладки на каждой вкладке.
