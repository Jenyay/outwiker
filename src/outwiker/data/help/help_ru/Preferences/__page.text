!! Настройки приложения

OutWiker разрабатывается таким образом, чтобы пользователь имел как можно больше возможностей для подстройки приложения по своему вкусу и под свои привычки. Большинство параметров можно изменить через диалог настроек, который вызывается с помощью пункта меню %notice%Правка - Параметры...%%. В приложении имеется очень много настроек, которые сгруппированы по множеству разделов, которые показаны в левой части диалога настроек.

%center%Attach:outwiker_opt_general.png

Все настройки хранятся в файле %notice%outwiker.ini%%, расположение которого зависит от операционной системы и режима работы приложения. Более подробно о расположении файла настроек написано в разделе [[Директории настроек -> page://config-dirs]].

На следующих страницах приводится описание всех имеющихся настроек по каждому разделу.
