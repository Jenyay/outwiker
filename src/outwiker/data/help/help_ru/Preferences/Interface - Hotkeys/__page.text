!! Интерфейс - Сочетания клавиш

%center%Attach:outwiker_opt_keys.png

В данном разделе можно установить или поменять горячие клавиши для вызова определенных действий программы. Большую часть окна занимает список всех возможных действий, для которых можно установить горячие клавиши. Над этим списком расположена строка поиска для фильтрации действий по названию. Ниже располагается поле для более подробного описания выбранного действия. В самом низу расположено поле ввода для установки горячей клавиши для выбранного действия.

Сочетания горячих клавиш, установленные по умолчанию, перечислены в разделе page://shortcuts.
