Поле ввода %notice%Формат заголовка главного окна%% позволяет задать шаблон, согласно которому будет формироваться заголовок главного окна OutWiker. В шаблоне могут быть использованы следующие макросы подстановки:

* %code%{page}%% - заголовок выбранной в данный момент страницы;
* %code%{subpath}%% - относительный путь до выбранной в данный момент страницы относительно корня дерева заметок;
* %code%{file}%% - имя директории, в которой хранится открытая в данный момент база заметок.

Эти макросы можно не набирать вручную, а вставить с помощью кнопки, расположенной справа от поля ввода. При ее нажатии будет показано выпадающее меню для вставки перечисленных макросов.

С помощью выпадающего списка %notice%Размер значков на кнопках%% можно изменять размер элементов интерфейса. По умолчанию используются самый мелкий размер значков - 16 x 16 пикселей. В выпадающем списке можно выбрать следующие варианты: 20 x 20, 24 x 24, 32 x 32, 48 x 48 пикселей. Это может быть полезно для мониторов с высоким разрешением.

С помощью флажка %notice%Отображать панель состояния%% можно скрывать или показывать статусную панель, расположенную в самом низу главного окна приложения.
