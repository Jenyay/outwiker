!! Плагины

%center%Attach:outwiker_opt_plugins.png

В данном разделе можно посмотреть список установленных [[плагинов -> page://plugins]]. При выборе плагина в списке будет отображаться информация о нем: название, номер версии, краткое описание и, если есть, ссылка на сайт этого плагина. 

Установленный флажок около названия плагина означает, что данный плагин активирован. Таким образом, для отключения плагина не обязательно его удалять из поддиректории %info%plugins%% [[директории настроек -> page://config-dirs]], можно его отключить в этом разделе настроек.

Внизу окна расположена ссылка на [[страницу сайта -> https://jenyay.net/Outwiker/Plugins]] со списком поддерживаемых плагинов.

В подразделах данного раздела плагины могут добавлять разделы со своими настройками.
