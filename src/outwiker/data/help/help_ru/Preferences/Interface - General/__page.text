%notice%Спрашивать подтверждение перед выходом%%. Если установлен этот флажок, то при попытке завершить приложение появится диалог для подтверждения завершения работы с OutWiker. 

Поле ввода %notice%Интервал автосохранения в секундах%% позволяет задать, как часто будет сохраняться открытая в данный момент заметка. Если значение равно 0, то автосохранение по таймеру будет отключено, но заметки также сохраняются и при других событиях: при выходе из программы, при переключении между заметками, при переключении между вкладками "Вики", "Просмотр" и "HTML" и др. Кроме того, принудительно сохранить заметку можно с помощью пункта меню %notice%Файл - Сохранить%%.

Поле ввода %notice%Размер истории последних используемых значков%% позволяет задать количество значков, которое будет храниться в списке последних используемых значков в диалоге создания и редактирования свойств страницы.

Поле ввода %notice%Размер истории открытых файлов%% позволяет задать, насколько длинным должен быть список последних открытых баз заметок в меню %notice%Файл%%.

Если установлен флажок %notice%При запуске открывать последний открытый файл%%, то после перезапуска программы будет открыта последняя используемая база заметок.

Поле ввода %notice%Задержка окна сообщений в секундах%% позволяет задать время в течение которого отображается информационное окно, появляющееся в правом нижнем углу окна программы в случае возникновения каких-либо ошибок или для уведомления о каком-либо событии, произошедшем в программе.

Некоторые типы страниц (например, [[викистраницы -> page://wiki-page]] и [[HTML-страницы -> page://html-page]]) могут отображаться в разных режимах - в [[режиме просмотра -> page://settings_interface_preview]] и в режиме редактирования текста заметки. С помощью выпадающего списка %notice%Режим открытия страниц по умолчанию%% можно выбрать, в каком из этих режимах будет открываться страница при ее выборе в дереве заметок. С помощью данного параметра можно сделать так, чтобы выбираемая страница изначально всегда открывалась в режиме просмотра или режиме редактирования, а также можно установить, что страница будет открываться в том режиме, в котором она была открыта при последнем посещении этой страницы.

С помощью выпадающего списка %notice%Язык%% можно выбрать один из поддерживаемых языков интерфейса. Если выбран пункт %notice%Авто%%, то язык будет выбираться автоматически в зависимости от настроек операционной системы. Если вы хотите помочь перевести интерфейс программы на какой-нибудь еще язык, то это можно сделать с помощью веб-сервиса [[crowdin.com -> https://crowdin.com/project/outwiker]].
