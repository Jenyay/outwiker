!! Интерфейс - Дерево заметок

%center%Attach:outwiker_opt_note_tree.png

Этот раздел настроек предназначен для изменения внешнего вида панели %notice%Заметки%%, на которой отображается дерево заметок.

С помощью выпадающего списка %notice%Размер шрифта%% можно изменять размер шрифта, которым отображаются заголовки заметок в дереве заметок. Если в этом выпадающем списке выбран пункт %notice%Размер по умолчанию%%, то будет использован размер шрифта, установленный в операционной системе для элементов интерфейса.

С помощью выпадающего списка %notice%Размер значков%% можно изменять размер значков, которые отображаются рядом с каждой заметкой в дереве заметок. По умолчанию используются самый мелкий размер значков - 16 x 16 пикселей. В выпадающем списке можно выбрать следующие варианты: 20 x 20, 24 x 24, 32 x 32, 48 x 48 пикселей. Это может быть полезно для мониторов с высоким разрешением.

С помощью флажка %notice%Отображать значки заметок%% можно включать или отключать отображение значков около заголовков заметок в дереве заметок.

В группе %notice%Дополнительные значки%% можно включать или отключать отображение значков, которые могут быть добавлены рядом с основным значком при некоторых условиях:

* Флаг %notice%Показывать значок закладки%% включает или отключает дополнительный значок, обозначающий, что данная страница добавлена в закладки.
* Флаг %notice%Показывать значок "Только для чтения"%% включает или отключает дополнительный значок, обозначающий, что данная страница открыта в режиме только для чтения.

В данной версии OutWiker имеется два вида встроенных дополнительных значков, но [[плагины -> page://plugins]] могут добавлять свои дополнительные значки. Так, например, плагин [[RecentEditedPages -> https://jenyay.net/Outwiker/RecentEditedPages]] добавляет значок, обозначающий, что данная страница редактировалась сегодня.
