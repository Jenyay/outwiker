!! Редактор - HTML-редактор

%center%Attach:outwiker_opt_editor_html.png

Данный раздел содержит настройки для раскраски HTML-кода в редакторе заметок на [[HTML-страницах -> page://html-page]] или на вкладке просмотра кода HTML на [[вики-страницах -> page://wiki-page]]. Здесь можно задать цвет и стиль шрифта для HTML-тегов, их атрибутов, чисел, HTML-комментариев, а также ошибочных HTML-тегов, которые не входят в словарь известных HTML-тегов.

Пример раскраски HTML-кода показан на следующем рисунке:

%center%%thumb width=600%Attach:html_highlight.png%%

Имя шрифта и его размер для редактора заметок устанавливаются в разделе page://settings_editor_general.
