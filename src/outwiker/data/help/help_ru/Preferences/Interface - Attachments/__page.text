!! Интерфейс - Вложения

%center%Attach:outwiker_opt_attach.png

В этом разделе содержатся настройки поведения панели %notice%Вложения%%.

%center%%thumb width=700%Attach:attach_panel.png%%

С помощью выпадающего списка %notice%Двойной клик или Enter на вложении%% можно выбрать, какое действие должно произойти при соответствующем событии. Выпадающий список содержит два варианта действия:

* %notice%Запустить вложение%%, то есть открыть выбранный файл в программе, ассоциированной с данным типом файлов или запустить приложение, если это выполняемый файл (exe-файл под Windows).
* %notice%Вставить ссылку на вложение%%. Для тех [[типов страниц -> page://page-types]], которые позволяют добавлять ссылки на файлы в текст заметки ([[вики-страницы -> page://wiki-page]] и [[HTML-страницы -> page://html-page]]), вставить нотацию, которая будет преобразована в ссылку на выбранный файл или файлы.

С помощью флажка %notice%Показывать скрытые папки%% можно включить или отключить отображение папок, который начинаются с двух символов подчеркивания %info%__%%. Такие файлы считаются служебными и по умолчанию скрыты от пользователя. В данной версии используется только один тип скрытых папок, которые создаются внутри папки со вложениями - %info%__thumb%%. Эта папка содержит, например, файлы миниатюр для изображений на странице. Плагины могут создавать и другие подобные папки, которые не следует показывать пользователю, а также использовать папку %info%__thumb%% для своих нужд.
