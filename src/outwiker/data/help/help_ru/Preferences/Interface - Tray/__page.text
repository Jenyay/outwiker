!! Интерфейс - Значок в области уведомлений

%center%Attach:outwiker_opt_tray.png

Настройки в этом разделе предназначены для установки поведения иконки программы в области уведомлений (области со значками рядом с часами).

С помощью выпадающих списков %notice%Кнопка сворачивания окна%% и %notice%Кнопка закрытия окна%% можно выбрать поведение при нажатии соответствующих кнопок, расположенных в заголовке главного окна приложения.

Для кнопки сворачивания окна можно выбрать действия: %notice%Свернуть окно%% и %notice%Свернуть в область уведомлений%% (в последнем случае окно пропадет из панели задач, но будет отображаться в виде значка в области уведомления). Для кнопки закрытия окна предлагаются те же действие и еще вариант %notice%Закрыть окно%% (это то, что делает кнопка закрытия по умолчанию).

Флажок %notice%Запускаться свернутым в область уведомлений%% указывает приложению, что при запуске нужно сразу скрыть главное окно и отобразить значок в области уведомления. Это может быть удобно в тех случаях, если OutWiker у вас запускается автоматически при запуске операционной системы.

Флажок %notice%Всегда показывать значок в области уведомлений%% указывает программе, что значок приложения в трее должен отображаться всегда, а не только когда программа находится в свернутом состоянии.
