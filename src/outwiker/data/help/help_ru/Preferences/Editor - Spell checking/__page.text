!! Редактор - Проверка орфографии

%center%Attach:outwiker_opt_editor_spell.png

В этом разделе можно изменить настройки, влияющие на процесс проверки орфографии в текстовом редакторе для ввода заметок.

Если установлен флажок %notice%Пропускать слова с цифрами%%, то при проверке орфографии будут пропускаться слова наподобие "абырвалг123", "111одидватри", "один111один" и т.п.

OutWiker может использовать сразу несколько словарей для проверки орфографии. Если слово имеется хотя бы в одном из используемых словарей, то оно помечается как верное. В списке %notice%Используемые словари%% можно выбрать, какие именно словари использовать при проверке во время ввода текста. Количество одновременно используемых словарей может влиять на скорость работы редактора при обработке текста большого объема. 

Среди словарей имеется специальный словарь %notice%html%%, который содержит имена тегов для языка HTML.

Словари, которые использует программа OutWiker для проверки орфографии расположены в папке %info%spell%% в [[директориях настроек -> page://config-dirs]]. OutWiker использует формат словарей из LibreOffice для движка hunspell. Вы можете найти дополнительные словари, например, по [[этой ссылке -> https://github.com/LibreOffice/dictionaries/]] и скопировать их в папку %info%spell%%.

В поле ввода %notice%Пользовательский словарь%% перечислены слова, которые были добавлены пользователем. В этот список слова попадают, при добавлении их в словарь с помощью соответствующего пункта всплывающего меню, которое появляется при нажатии правой кнопки мыши на слове с ошибкой в редакторе заметок. В этом разделе настроек также можно добавлять и удалять слова, которые при проверке орфографии будут считаться верными. При этом каждое слово должно быть введено на отдельной строке.
