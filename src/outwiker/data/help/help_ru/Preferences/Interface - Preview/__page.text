Данный раздел отвечает за внешний вид заметок для [[HTML- -> page://html-page]] и [[викистраниц -> page://wiki-page]] в режиме просмотра. Некоторые [[плагины -> page://plugins]] добавляют новый тип страниц, которые также имеют режим просмотра. Эти параметры распространяются также и на эти типы страниц.

С помощью параметра %notice%Шрифт%% можно задать размер и начертание шрифта, который будет использоваться на странице по умолчанию.

В поле ввода %notice%Дополнительные стили (CSS)%% можно ввести собственные стили CSS, которые будут добавлены к каждой странице (если тип страниц поддерживает данный параметр). Этот параметр предназначен для уверенных пользователей программы, которые разбираются в языке CSS и хотят настроить внешний вид страниц под себя, не создавая собственные [[стили страниц -> page://styles]]. На этот случай парсер викистраниц добавляет множество классов CSS для различных элементов оформления в заметках, которые можно использовать для тонкой настройки внешнего вида.

Если подключен [[плагин -> page://plugins]] [[HtmlFormatter -> https://jenyay.net/Outwiker/HtmlFormatter]], то в этот раздел будет добавлена настройка %notice%Разделитель абзацев%%. Эта настройка позволяет переключаться между режимами оформления текстовых блоков, разделенных пустыми строками. С помощью выпадающего списка можно выбрать, каким образом будут формироваться отступы между блоками текста - с помощью тегов %code%&lt;br&gt;%% или с помощью обертывания их тегами %code%&lt;p&gt;...&lt;/p&gt;%%.
